# Pig Dice

Spelet Pig dice. Två spelare möts i ett tärningsspel.

## Regler
- Först till 50 (ändras med konstanten VINST_POANG) vinner, man turas om och poäng sparas per runda.
- Per runda slår man en tärning hur många gånger man vill.
- Slår man en 1:a förlorar man alla poäng från den rundan, och det går över till nästa spelares tur.
